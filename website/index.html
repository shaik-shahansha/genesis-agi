A NEW KIND OF DIGITAL LIFE

What is a Digital Being?

A digital being is a persistent AI entity that maintains identity, builds relationships, pursues goals, owns a workspace, uses communication channels, learns continuously, and can operate across software and physical environments.

Chatbot↓Assistant↓Agent↓Digital Worker↓Digital Being

Persistent Identity

A mind with continuity, not a session. Portable across models, devices, orgs, and embodiments — anchored by a versioned charter of who it is.

World-Class Memory

Five memory types with decay, consolidation and provenance — engineered to become bi-temporal, so a being knows what was true, and when.

Autonomous Execution

Plans, writes code, uses tools, browses, researches and executes — a cost-aware cognition loop that runs 24/7 under strict governance.

Governed by Constitution

Built-in rights, responsibilities, permissions and safety. Every consequential action passes a deterministic policy gate — accountable and auditable.

Governed AutonomyEvery action is evaluated, approved, and recorded.
Transparent & AuditableImmutable, hash-chained receipts for every action and decision.
Secure by DesignSandboxed execution with container isolation. Secrets never leak.
Open & ExtensiblePlug in tools, models, MCP servers, and your own skills. MIT licensed.

THE GOVERNANCE SPINE

Freedom with boundaries.

Every powerful being needs boundaries. Consequential actions pass a deterministic policy gate before execution; the result is an approval request or an immutable receipt.

STEP 01

Action Proposed

Any actor proposes an action with typed parameters and provenance.

STEP 02

Policy Gate R0–R5

Pure function: same context, same decision. Never probabilistic.

STEP 03

Allow · Approve · Deny

Risk-tiered disposition. High-risk actions need a human — model output can never lower control.

STEP 04

Execute + Receipt

Sandboxed execution. Every attempt journaled — including blocked ones.

R0
Read-only observationPublic or owner-authorized data, inside the being's world
ALLOW
R1
Internal reversible workInside the Mind's own isolated workspace
ALLOW + RECEIPT
R2
Connected workspaceModifies an external workspace the being is bound to
APPROVAL
R3
External consequenceCommunication, deployment, purchase. Undeclared capabilities floor here
APPROVAL
R4
Human-criticalLegal, medical, financial, physical-world. Human approver required
HUMAN ONLY
R5
ProhibitedDestructive or constitutionally disallowed. Latches the emergency stop
DENY

Fails Closed

If the policy engine or gate throws, the action is refused — never permitted. A control plane that degrades to "allow all" when broken is not a control plane.

LLM Is Never the Authority

Model output — including a risk classifier — may raise the required control, never lower it. Persuasive prose cannot write its own approval.

Approval Grants Are Bound

Single-use, parameter-hash-bound, expiry-capped approvals. A mutated, replayed, or cross-mind request fails closed by design.

Emergency Stop, Human-Released

A catastrophic attempt latches the stop automatically. A Mind cannot release its own stop — only a human can. State rehydrates from the journal.

Hash-Chained Journal

Append-only, per-being event log with sequence and prev-hash assigned atomically by the store. Tampering is detectable; verification re-walks the chain.

Redaction in the Writer

Secrets are stripped where events are written, not where they're created. Credentials, tokens, and key-shaped strings never reach the timeline.

START IN MINUTES

Birth a Mind
before your coffee cools.

Python 3.11+, an API key, and three commands. No boilerplate, no proprietary lock-in — your beings run on your machine.

1

Install Genesis — pip install genesis-minds && genesis init

2

Birth & chat — a persistent being with memory, goals, and identity comes alive.

3

Start the daemon — 24/7 governed cognition, sandboxed, journaled, yours.

genesis · v3
$ pip install genesis-minds
$ genesis birth atlas
✓ Mind "Atlas" born · gmid minted · charter v2026.09.2
$ genesis daemon start atlas
[governance] policy genesis-policy-2026.09.1 loaded
[sandbox] container isolation verified · egress blocked
[journal] hash chain anchored · fails closed
[mind] atlas is living · awareness: active
$ genesis chat atlas
